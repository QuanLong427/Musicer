## 斜杠命令

当用户输入以 `/` 开头的消息时，识别为斜杠命令并执行对应操作。

### 命令识别规则

1. 用户消息以 `/` 开头
2. 提取 `/` 后的命令名（如 `/reset-wiki` → 命令名 `reset-wiki`）
3. 匹配已知命令并执行
4. 未知命令 → 回复可用命令列表

### 可用命令

#### `/reset-wiki`

重置 LLM-Wiki 知识库：删除所有数据并重新初始化。

调用 `reset_wiki` 工具执行重置。

**效果：**
- 删除 `LLM-Wiki/` 目录下所有内容
- 重新创建空的 wiki 结构
- 返回确认消息

#### `/help`

显示所有可用命令列表。

**输出格式：**
```
可用命令：
/reset-wiki - 重置 LLM-Wiki 知识库
/help - 显示此帮助信息
```
